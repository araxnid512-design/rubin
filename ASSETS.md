# Бесплатные ассеты

Где брать графику, звук и шрифты со свободной лицензией. Перед скачиванием
проверяй лицензию конкретного пака: на агрегаторах (OpenGameArt, itch.io)
у каждого автора своя.

## Где искать

| Источник | Что есть | Лицензия |
|----------|----------|----------|
| [Kenney](https://kenney.nl/assets) | 2D-спрайты top-down (люди, оружие, тайлы), UI, звуки интерфейса | CC0 |
| [OpenGameArt](https://opengameart.org/) | спрайты, тайлсеты, музыка, эффекты; поиск по «zombie», «post-apocalyptic», «top-down» | разная: CC0, CC-BY, GPL |
| [itch.io: бесплатные ассеты](https://itch.io/game-assets/free) | тайлсеты постапокалипсиса, зомби, пиксель-арт | у каждого пака своя |
| [Freesound](https://freesound.org/) | звуки: шаги, выстрелы, рычание, ветер | CC0 / CC-BY / CC-BY-NC (NC не брать, если игра может стать платной) |
| [Sonniss GDC Game Audio Bundle](https://sonniss.com/gameaudiogdc) | большие пакеты профессиональных звуков | роялти-фри, без указания авторства |
| [Pixabay: музыка и звуки](https://pixabay.com/music/) | фоновая музыка, эмбиент | Pixabay Content License |
| [Incompetech (Kevin MacLeod)](https://incompetech.com/music/) | музыка, в том числе мрачная/хоррор | CC-BY 4.0 |
| [Google Fonts](https://fonts.google.com/) | шрифты с кириллицей (например, PT Sans, Rubik, Russo One) | OFL |
| [game-icons.net](https://game-icons.net/) | иконки предметов и способностей (SVG) | CC-BY 3.0 |
| [Poly Haven](https://polyhaven.com/) | текстуры (асфальт, трава, бетон) для фонов | CC0 |
| [Lospec](https://lospec.com/palette-list) | палитры для пиксель-арта | бесплатно |

Ссылки собраны из общих знаний, без проверки из этого окружения (сеть ограничена).
