# Правила проекта «Гарнизон»

Мобильная игра: командир воинской части в зомби-апокалипсисе, вид сверху.
Код: HTML/JS/Canvas в `www/`, обёртка Capacitor (Android) в `android/`.
Дизайн и план — `docs/DESIGN.md`. Прежняя игра по миру «Стикс» — в `docs/stiks/`
и в истории git, к текущей игре её лор не относится.

## Код
- `www/js/data.js` — все числа баланса. Механики не хардкодят числа.
- `grid.js` — сетка 1 м, поля потоков (пути для любого числа юнитов), видимость.
- `maps.js` — генерация районов города и карты части.
- `battle.js` — боевой движок: режимы `base`, `sortie`, `defense`.
- `campaign.js` — дни, ресурсы, итоги боёв, сохранение (`localStorage`, в try/catch).
- `render.js`, `ui.js`, `main.js` — отрисовка, окна, экраны и управление.
- Перед изменением баланса прогоняйте симуляцию (боты в Playwright) и смотрите
  потери и расход патронов, а не только «работает ли».

## Ассеты
- Только ассеты со свободной лицензией (CC0, CC-BY и т. п.), см. `ASSETS.md`.
- Каждый добавленный файл записывай в таблицу в `ASSETS.md`: путь, источник, автор, лицензия.
- Ассеты кладутся в `www/assets/`.

## Android
- Ориентация только горизонтальная (`sensorLandscape` в манифесте + lock из JS).
- Полный экран: immersive-режим в `MainActivity.java`, StatusBar скрыт из JS.
- Кнопка «Назад» никогда не закрывает игру: закрывает окно, иначе пауза / выход из паузы
  (`www/js/platform.js`, `Platform.onBack` в `main.js`). Выход только кнопкой в меню паузы.
- Сворачивание приложения ставит игру на паузу.

## Сборка
- `npm install`, затем `npm run serve`: игра в браузере на http://localhost:8080
  (тап — приказ отряду, перетаскивание — карта, колесо — масштаб, Esc — пауза).
- `npm run sync` копирует `www/` в Android-проект.
- APK собирает GitHub Actions (`.github/workflows/android-apk.yml`) при каждом push в `main`
  и в ветки `claude/**`, и публикует в Releases как `garrison.apk`. Подпись debug-ключом
  `android/app/debug.keystore` (постоянный, чтобы обновления ставились поверх).
  Для публикации в магазин нужен отдельный release-ключ, его в репозиторий не класть.
- Плагины Capacitor подключаются без сборщика: `scripts/copy-vendor.js` копирует их
  браузерные сборки в `www/vendor/`. Новый плагин добавляй в этот скрипт и в `index.html`.
