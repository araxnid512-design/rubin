# Правила проекта «Стикс»

Игра по миру «Стикс» / «Улей» (Артём Каменистый, включая «Человеческий улей»).
Код: HTML/JS/Canvas в `www/`, обёртка Capacitor (Android) в `android/`.

## Лор

1. Перед любой новой механикой, мутантом, предметом или локацией сверяйся с `LORE.md`.
2. Если в `LORE.md` нужного нет, ищи в интернете (фанатские вики, обзоры, описания
   книг) и дополняй файл, указывая источник у каждого факта.
3. Не выдумывай лор. Если источник недоступен (нет сети, сайт заблокирован),
   скажи об этом пользователю и оставь пункт с пометкой «нужен источник».
4. Не копируй текст книг. Только факты и термины, своими словами.
5. Если механика расходится с лором ради геймплея (например, оружие без патронов),
   добавь запись в раздел «Отступления от канона» в `LORE.md`: что в каноне,
   что в игре, зачем.

## Ассеты

- Только ассеты со свободной лицензией (CC0, CC-BY и т. п.), см. `ASSETS.md`.
- Каждый добавленный файл записывай в таблицу в `ASSETS.md`: путь, источник, автор, лицензия.
- Ассеты кладутся в `www/assets/`.

## Android

- Ориентация только горизонтальная (`sensorLandscape` в манифесте + lock из JS).
- Полный экран: immersive-режим в `MainActivity.java`, StatusBar скрыт из JS.
- Кнопка «Назад» никогда не закрывает игру: пауза / выход из паузы (`www/js/platform.js`).
  Выход из приложения только кнопкой в меню паузы.
- Сворачивание приложения ставит игру на паузу.

## Сборка

- `npm install`, затем `npm run serve`: игра в браузере на http://localhost:8080
  (WASD/стрелки, пробел: огонь, Esc: пауза).
- `npm run sync` копирует `www/` в Android-проект.
- APK собирает GitHub Actions (`.github/workflows/android-apk.yml`) при каждом push в `main`
  и публикует в Releases. Подпись debug-ключом `android/app/debug.keystore`
  (постоянный, чтобы обновления ставились поверх). Для публикации в магазин нужен
  отдельный release-ключ, его в репозиторий не класть.
- Плагины Capacitor подключаются без сборщика: `scripts/copy-vendor.js` копирует их
  браузерные сборки в `www/vendor/`. Новый плагин добавляй в этот скрипт и в `index.html`.
