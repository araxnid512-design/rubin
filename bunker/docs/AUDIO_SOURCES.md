# Звуки BUNKER SURVIVAL — источники и лицензии

Все файлы в `assets/audio/` — настоящие записи из открытых наборов под лицензиями, разрешающими коммерческое использование: **CC0** (общественное достояние, указание автора не требуется) и **CC-BY** (обязательно указание автора — см. раздел «Указание авторов» ниже). Записей с NC/ND/Sampling+, с неясной лицензией и вырезанных из коммерческих игр и фильмов нет.

Код загружает звуки только по имени через `Core.sfx(имя)`: варианты `<имя>_1..12.ogg` выбираются случайно, одиночный звук — `<имя>.ogg`. Звуки среды `amb_*` (и `heartbeat`) зациклены без шва (хвост вклеен кроссфейдом в начало), код включает `loop = true` сам.

## Общая обработка

- Формат: Ogg Vorbis, качество `-q:a 4`, 44.1 кГц. Разовые звуки — моно, `amb_wind`, `amb_drip`, `amb_night` — стерео.
- Разовые звуки: обрезка тишины в начале и конце, фейды (вход 1–10 мс, выход 20–600 мс), пик около −1 dBFS; у вариантов одного звука громкость выровнена (более громкие приглушены до медианы набора).
- Звуки среды: цикл 15–32 с (`amb_generator` 16 с, `amb_drip` 19 с, `amb_geiger` 20 с, `amb_hum` 24 с, `amb_wind` 31.5 с, `amb_night` 32 с), без резкого шва; громкость по RMS близка к прежним синтезированным звукам, чтобы не менять баланс в `env_system.gd`.
- Проверка (прослушать нельзя): длительность, пик/RMS, отсутствие клиппинга и тишины, непрерывность на шве цикла, осциллограммы и спектрограммы сомнительных файлов. Импорт Godot — без ошибок.
- Обработка сделана скриптами numpy + ffmpeg вне репозитория; старый синтезатор `tools/gen_audio.py` больше не используется.
