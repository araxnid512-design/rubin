# Проверка на телефоне (WP33 Pro, Android 13)

Сборка проверена автотестами на ПК (рендер OpenGL через Mesa llvmpipe). **На реальном телефоне APK не
запускался** — в среде разработки нет подключённого устройства. Ниже — проверка, которую нужно пройти вручную,
около 15–20 минут. Результаты удобно присылать снимками экрана с включённой панелью разработчика.

## Подготовка

1. Установить `BunkerSurvival.apk`. Разрешить установку из этого источника.
2. Запустить и выбрать «Новая игра».
3. Пауза → «Настройки графики и управления» → «Панель разработчика: Вкл».
4. Начать на среднем качестве: FPS 60, авто-разрешение включено.

## Сценарий (отметить ✓ / ✗ и записать FPS из панели)

| № | Что сделать | Что должно быть | FPS (ср.) |
|---|---|---|---|
| 1 | Подождать на старте 10 с | Жилой отсек, герой у ковра, интерфейс не перекрыт вырезом камеры | |
| 2 | Пройти джойстиком по жилому отсеку | Герой идёт лицом вперёд, без хождения боком; ноги не скользят | |
| 3 | Лёгкий наклон джойстика, затем полный 3–4 с, затем «Присед» | Лёгкий — шаг, полный — бег, через 2 с — рывок (тратит выносливость); в приседе медленный шаг, кнопка подсвечена | |
| 4 | Выйти в коридор (дверь уже открыта) | Камера ближе, стены вокруг героя «вырезаются», видно, где он | |
| 5 | Открыть «Гермодверь шлюза» | Клип открывания, створка медленно уходит, лампа над дверью зелёная | |
| 6 | В шлюзе: «Надеть защитный костюм» | Клип надевания, модель меняется на героя в костюме | |
| 7 | Открыть «Гермодверь лестницы», подняться по лестнице | Подъём ровный, стопы на ступенях, наверху надпись «Спуск в убежище» | |
| 8 | Открыть «Гермодвери убежища» и выйти наружу | Плавно меняется свет, звучит ветер, надпись «Поверхность», дозиметр жёлтый | |
| 9 | Подойти к грузовику | Мощность дозы растёт, дозиметр щёлкает чаще, цвет — оранжевый/красный | |
| 10 | Найти мародёра у постройки | Он догоняет и бьёт; «Удар» — герой бьёт в ответ; мародёр вздрагивает и падает | |
| 11 | Зайти в разрушенную постройку | Крыша скрывается, «Подобрать: фильтр противогаза» | |
| 12 | Повернуть камеру пальцем, приблизить двумя пальцами | Плавно, кнопки не срабатывают случайно, большой палец легко достаёт «Действие», «Удар» и «Присед» | |
| 13 | Вернуться в бункер, снять костюм, в медпункте — «Медоборудование» | Доза уменьшается, здоровье растёт | |
| 14 | Лечь на кровать, встать | Герой ложится на матрас, «Действие» — встаёт | |
| 15 | Пауза → «Сохранить игру», свернуть приложение на 1 минуту, вернуться | Игра продолжается с того же места, звук вернулся | |
| 16 | Закрыть приложение полностью, запустить снова → «Продолжить» | Герой там же, двери и свет как были, вещи в инвентаре | |
| 17 | Качество «Высокое», затем «Низкое» | Меняется чёткость и тени, FPS растёт на низком | |
| 18 | Поиграть ещё 5 минут без остановки | Нет вылетов, телефон не перегревается сильно, FPS не падает со временем | |

## Что прислать

- Снимки панели разработчика: в бункере, на лестнице, на поверхности у грузовика. Нужны FPS, время кадра, вызовы отрисовки и ОЗУ.
- Что не работало или выглядело неправильно: анимации, кнопки, вырез экрана, звук.
- Если FPS на среднем качестве ниже 30, то же на низком.
