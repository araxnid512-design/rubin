Если окно установки не появилось: в Chrome ⋮ → «Встановити додаток» или «Додати на головний екран».

Или приложение APK

⬇ Скачать APK около 200 КБ
  1. Нажмите «Скачать APK» — файл маленький, скачается за секунду.
  2. Откройте его из уведомления → «Встановити».
  3. Если Android спросит — «Налаштування» → «Дозволити з цього джерела» → назад → «Встановити».
  4. Окно Play Захисту → «Встановити все одно». Затем «Відкрити» — игра запустится.
