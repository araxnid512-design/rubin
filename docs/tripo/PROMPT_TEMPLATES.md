# Шаблоны промптов для Tripo

Промпты для Tripo пиши на английском (точнее результат). Общий хвост стиля добавляй ко всем:

**STYLE:** `realistic post-apocalyptic style, worn, dirty, muted colors, game asset, low poly optimized, clean topology, single object, centered, full object visible, neutral background`

## Персонаж / заражённый
`[описание], full body, T-pose, arms straight out to the sides, legs slightly apart, empty hands, symmetrical, + STYLE`

Пример (бегун):
`thin infected human runner, torn dirty clothes, grey sickly skin, hunched posture, long limbs, full body, T-pose, arms straight out to the sides, legs slightly apart, empty hands, + STYLE`

## Оружие
`[оружие], side view, single piece, no hands, no attachments unless stated, + STYLE`

Пример:
`AK-47 assault rifle, scratched wooden furniture, worn metal, side view, single piece, no hands, + STYLE`

## Мебель
`[предмет], 3/4 front view, standing on the floor, real-world proportions, + STYLE`

## Набор мелочи (для сегментации)
`set of separate small objects laid out in a grid with clear space between them: [список], top-down 3/4 view, no overlapping, + STYLE`

## Правила
- Один объект — одна генерация (кроме набора мелочи).
- Без текста, логотипов, надписей.
- Если результат неудачный — менять 1–2 детали промпта, а не переписывать всё.
