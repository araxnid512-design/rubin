# Пакет правил для работы с Tripo (игра «Стикс»)

Что внутри:
- START_MESSAGE.txt — первое сообщение для Claude Code (скопировать и отправить).
- TRIPO_RULES.md — постоянные правила: бюджет, качество, оптимизация, анимации.
- ASSET_LIST.md — список моделей по приоритету с лимитами полигонов.
- PROMPT_TEMPLATES.md — шаблоны промптов для Tripo, чтобы попадать с первой генерации.
- tripo_budget.md — журнал расхода кредитов.

Как использовать:
1. Прикрепи этот архив в сессии Claude Code (кнопка «+») или загрузи в корень репозитория.
2. Отправь текст из START_MESSAGE.txt.
