# «Дрейф» — журнал кредитов Tripo

Кредиты списываются с аккаунта Studio. Генерацию запускает программа `tripo` в GitHub Actions
(`.github/workflows/tripo-dw.yml`, задания — `tools/tripo/jobs.json`). Результаты сборка кладёт в ветку
`tripo-status` (`files/`, журнал `results.md`).

Баланс Studio на старте: **5385**.

| 2 | Пират | 75 | готово, sd_pirate |

## Этап 2 (15.11): решение пользователя «можешь 2–3000 кредитов взять»
Предел этапа — **2000** (нижняя граница разрешённого). Генерацию нужно остановить, когда баланс Studio дойдёт
до **2940**.

Заданий 28, ожидаемо **1660**:
- 6 персонажей по 75 (модель + скелет + готовые движения бесплатно):
  - ползун-пришелец;
  - главарь пиратов (босс);
  - экипаж: медик, стрелок, механик;
  - торговец станции.
- 22 предмета по 55:
  - на корабль: реактор, пульт мостика, верстак, медкапсула, двигатель, ящик, контейнеры, фабрикатор, койка,
    шкафчик, терминал склада, кресло капитана, генератор щита, жизнеобеспечение, баллоны;
  - для событий: руда трёх видов, прилавок торговца, обломки, разбитый робот, сундук пиратов.

Задания подхватил тот же запуск 11. Его собственный предел — 2000 от баланса 5385, из них 445 уже
потрачены, поэтому последние задания могут остаться невыполненными. Они пойдут в следующий запуск, и в списке
будут только они.
