# Nova 2.5D — собственный движок (прототип)

TypeScript + WebGL2. Сейчас это демо-сцена (`src/demo/main.ts`), на ней проверяется ядро:
- отсек корабля: мостик, коридор, реактор;
- герой, пират и робот (спрайты из 3D-моделей «Дрейфа»), два дрона, турель;
- перестрелка с зарядами и искрами;
- интерфейс в стиле космоса (HTML поверх картинки).

## Что уже есть
- `src/engine/gfx.ts`:
  - отрисовка пакетами (подряд идущие спрайты с одной текстурой рисуются за один вызов);
  - свет до 16 источников, направление света — по картам нормалей;
  - режим сложения цветов для вспышек и звёзд;
  - текстуры из PNG и нарисованные кодом.
- `src/engine/core.ts`:
  - проекция 2.5D: 1 м = 64×45 px, стена 113 px;
  - спрайты в 8 направлениях (атласы с нормалями), анимация, тень;
  - корабль из клеток: отсеки, стены высокие и в разрезе, двери, столкновения;
  - частицы: заряды, искры, свечение;
  - ввод: клавиатура и джойстик.

## Чего ещё нет
- звук;
- нажимаемые кнопки интерфейса;
- поиск пути и ИИ;
- сохранение;
- сборка APK (WebView, через GitHub Actions);

## Запуск
```
npm i
npm run build              # public/game.js
npm run shot               # снимок в shots/demo.png (Chromium)
```
Для игры в браузере отдать папку `public/` любым HTTP-сервером. Управление: WASD или стрелки.
