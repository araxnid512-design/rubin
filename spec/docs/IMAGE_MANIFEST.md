# Привязка визуальных образцов к файлам и объектам

Все изображения в `references/` — **дизайн-референсы**, а не готовые текстуры земли или 3D-модели. Их нельзя просто поставить плоским фоном вместо игрового мира.

| Изображение | Содержание | Как использовать |
| --- | --- | --- |
| `maps/01_friendly_home_with_scrap.png` | Наша территория 300×300, зелёная, поле металлолома на востоке | Ландшафт №1, дорога и ресурсная зона |
| `maps/02_central_battlefield_empty.png` | Центральное поле 300×300, открытая долина, воронки и болото | Ландшафт №2, без боя/ресурсов до 30:00 |
| `maps/03_enemy_home_with_scrap.png` | Каменистая территория 300×300, поле металлолома справа | Исходный ландшафт №3 **до** автономного строительства |
| `buildings/vehicles_three_variants.png` | Слева гараж, в центре автоцех, справа бронезавод | Создать три отдельные 3D-сцены техники |
| `buildings/weapons_three_variants.png` | Слева оружейный верстак, мастерская, завод | Три отдельные 3D-сцены оружия |
| `buildings/ammo_three_variants.png` | Слева патронный верстак, цех, завод | Три отдельные 3D-сцены боеприпасов |
| `interface/wrench_construction_menu.png` | Выбранный ключ, три вкладки, три карточки, ghost-строительство | Воссоздать мобильное меню и предпросмотр |

Схема на интерфейсном фото **иллюстративна**: окончательное название и цена каждой карточки берутся из `data/buildings.json`, логика из `docs/CONTROLS_AND_UI.md`. Если текст/положение в фото и техническом документе конфликтуют, действуют данные JSON и текстовые требования.

## Подготовка 3D-аватарок для Tripo AI

- **Отдельные изображения всех моделей:** `references/tripo/models/*.jpg` — каждое содержит только один объект, полное отображение на светлом фоне. Это вход для поштучного image-to-3D в Tripo AI.
- **Общие фотолисты:** `references/tripo/sheets/*.jpg` — для выбора стиля и сравнения трёх соседних моделей.
- **Бункер без крыши:** `references/tripo/bunker_interior_roof_hidden.jpg` — референс механики, НЕ модель для автоматического переноса.
- Полный список `ID ↔ имя JPG ↔ будущая GLB-модель` и инструкция по импорту — `docs/TRIPO_ASSET_CATALOG.md`.
- Фотография текущего UI показывает **3 категории**, но актуальное требование после добавления казармы/штаба/бункера — **4 категории × 3 здания**.

## Два кадра после 30 минут и модели противника

| Файл | Что изображено | Важное ограничение |
| --- | --- | --- |
| `stages/enemy_home_after_30min.jpg` | Уже самостоятельно выросшая вражеская база, металл справа, люди и несколько мастерских | **Тот же сектор №3**, не четвёртая карта; игрок туда не входит |
| `stages/battlefield_after_30min.jpg` | Центральная открытая долина с малыми отрядами двух сторон | **Тот же сектор №2**, сражаться только после 1800 секунд |
| `tripo/sheets/characters_enemy.jpg` | Вражеский рабочий, механик, солдат | В `tripo/models/` есть три отдельных JPG |
| `tripo/sheets/buildings_enemy_military.jpg` | Вражеская казарма, штаб, бункер | В `tripo/models/` есть три отдельных JPG |

Новые шесть JPG доводят каталог до **54 одиночных референсов** и **18 фотолистов**. Вместо дополнительной модели каждого автомата или грузовика у противника можно использовать те же GLB с другими материалами и обозначением фракции. Не путать фотоконцепты после 30 минут с уже работающей геометрией/боевыми NPC.
