# Каталог 3D-аватарок — импорт в Tripo AI

В папке `references/tripo/models/` подготовлены **54 отдельных JPG**, по **одному изолированному объекту** на изображение. Это визуальные 3D-референсы на светлом фоне (не готовые 3D-модели). Все изображения оригинальные для проекта «Линия снабжения», не скопированные из Foxhole. В `references/tripo/sheets/` лежат **18 сводных трёхобъектных изображений** для сравнения вариантов. При необходимости можно заново выделить отдельные JPG командой `bash tools/split_tripo_sheets.sh` (нужен ImageMagick).

## Особое изображение бункера

`references/tripo/bunker_interior_roof_hidden.jpg` — отдельный иллюстративный референс того, как **камера сверху видит человека внутри бункера через невидимую крышу**. Не передавать в Tripo как модель целого бункера: картинка содержит персонажа и интерьер, поэтому генератор может слить их в один меш. Для внешней модели использовать `military_bunker.jpg`; интерьер и крышу делать отдельно в Godot.

## Как по этим фото получить 3D-модели

1. Открыть Tripo AI → режим **Image to 3D**. Выбрать **одно** изображение `references/tripo/models/<id>.jpg`, а не целый фотолист.
2. Построить mesh, визуально проверить, что предмет целиком появился, не прирос к полу и не вобрал чужие предметы. При необходимости перегенерировать отдельно с тем же изображением.
3. Экспортировать модель в **GLB**. Сохранить с именем `<id>.glb`. Можно использовать условную папку `Godot_Starter/assets/models/` (её Codex создаст, когда модели будут готовы).
4. Проверить реальные размеры: основание каждого здания (`footprint_m`) хранится в `data/buildings.json`; у людей рост около 1.7–1.9 м; машины должны проходить по 6–8-метровой дороге. Установить правильный pivot на земле и направление модели (-Z вперёд).
5. Для мобильного Godot выполнить упрощение меша/текстур, освещение и LOD; сделать свои `CollisionShape3D`. Оружию — крепление к рукам, NPC — скелет и анимации, технике — колёса и логическую физику **отдельно от GLB**.
6. Бункер обязательно разделить на стены, пол, крышу, вход и интерьер. Если Tripo вернул монолит, не скрывать весь бункер — смоделировать `RoofVisual` отдельно. После входа игрока скрывается **только визуальная крыша**, коллизия остаётся.
7. Привязать каждый `.glb` к соответствующему **точному ID** из JSON и не заменять фотографии на плоские спрайты внутри 3D-сцены.

Ограничения: генеративные фото служат визуальными подсказками и могут иметь неидеальную геометрию, пропорции или механические детали. Перед финальным 3D-импортом модели нужно вручную осмотреть и исправить. На этом этапе **в ZIP нет готовых `.glb`**, зато есть 54 входных изображения для их создания. Дополнительно в `references/stages/` два кадра уже развившейся вражеской базы и центрального поля после открытия боя — это **сцены**, не отдельные модели для Tripo.
