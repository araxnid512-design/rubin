# Генератор голосов «Чаровника»

Озвучивает реплики героинь заранее: у каждой — свой голос (базовый диктор, высота, темп, тембр, эффекты).
Игра находит запись по хешу «героиня|текст» и проигрывает её; если записи нет — говорит системный синтезатор речи.

```
sudo apt install rhvoice rhvoice-russian sox opus-tools      # один раз
node tools/charmer-voice/extract.js    # собрать все реплики из игры → lines.json
python3 tools/charmer-voice/synth.py   # озвучить → charmer/src/main/assets/www/voice/
```

После правки текстов запустите оба шага ещё раз: новые реплики доозвучатся, устаревшие записи удалятся.
Характер голоса каждой героини — таблица `PROFILES` в `synth.py`; после её правки увеличьте `VER`.

Движок — [RHVoice](https://github.com/RHVoice/RHVoice); используются голоса Анна, Елена и Ирина
(свободные лицензии LGPL/GPL). Голоса Арина, Татьяна и Виктория распространяются только для
некоммерческого использования, поэтому здесь не применяются.
