# Модели Tripo для «Мёртвого мира»

Кредиты — с сайта Studio (аккаунт пользователя), тратит официальная программа `tripo` в GitHub Actions
(`.github/workflows/tripo-dw.yml`), устройство перенесено из игры «Стикс» (ветка `ccr-f5d34f3a-q7wlgf`).

- `jobs.json` — задания (исполнитель берёт каждое один раз; `"stop": true` — остановить).
- `start.txt` — изменить и отправить в ветку, чтобы запустить сборку (ждёт задания 150 минут).
- `chain.py` — модель по тексту → скелет → готовые движения `preset:biped:*` → файлы в `out/`.
- Готовые файлы и журнал (`results.md`) сборка выкладывает в ветку `tripo-status` (`files/`).
- Журнал кредитов — `budget.md`.

Если сохранённый вход устарел: Tripo пришлёт код на почту аккаунта → положить его в секрет репозитория
`TRIPO_CODE` → изменить `code.txt` (сборка «Tripo: код (Мёртвый мир)» передаст его ждущей сборке).
