# Живая книга: офлайн-квест

Текстовая ролевая игра для Android. Ты добавляешь свою книгу из памяти телефона, выбираешь героя и пишешь действия
обычными словами. Сцены сочиняет языковая модель Qwen3-0.6B, которая работает прямо на телефоне. Интернет не нужен:
у приложения нет разрешения на доступ к сети.

Реальные результаты проверок — в файле [ОТЧЁТ.md](ОТЧЁТ.md). Там же перечислено, что проверить не удалось.

## Что нужно, чтобы играть

Три вещи:

1. **Приложение** — файл `dist/zhivaya-kniga-debug.apk` (28 МБ). Модель в него не входит.
2. **Модель** — файл `Qwen3-0.6B-Q4_K_M.gguf` (397 МБ). Его нужно один раз скачать и положить на телефон.
3. **Русский голос** — системный синтез речи Android с голосом, скачанным на телефон. Без него игра работает, но молча.

### Шаг 1. Установить приложение

1. Скопируй `zhivaya-kniga-debug.apk` на телефон (по USB-кабелю в папку «Загрузки» или любым удобным способом).
2. Открой файл на телефоне. Android спросит разрешение на установку из этого источника — разреши.
3. Нажми «Установить».

Через компьютер то же самое делается командой `adb install zhivaya-kniga-debug.apk`.

### Шаг 2. Скачать и установить модель

1. На компьютере или телефоне скачай файл по ссылке:
   `https://huggingface.co/unsloth/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf`
2. Проверь контрольную сумму SHA-256 (не обязательно, но так надёжнее):
   `ac2d97712095a558e31573f62f466a3f9d93990898b0ec79d7c974c1780d524a`
   - Windows (PowerShell): `Get-FileHash Qwen3-0.6B-Q4_K_M.gguf -Algorithm SHA256`
3. Скопируй файл на телефон — во внутреннюю память или на карту памяти.
4. В приложении нажми **«Установить модель из файла»** и выбери этот файл.

Приложение проверит файл (формат GGUF, архитектура qwen3, размер, контрольная сумма), скопирует его к себе и сразу
замерит скорость на твоём телефоне. После этого исходный файл можно удалить.

### Шаг 3. Настроить русский голос (один раз, с интернетом)

1. Открой в приложении «Настройки» → «Системные настройки речи».
2. Выбери движок синтеза (на большинстве телефонов это «Синтезатор речи Google»).
3. Выбери язык «Русский» и скачай голосовые данные.
4. Вернись в приложение. В разделе «Голос рассказчика» должно появиться «Офлайн-голос готов».

Приложение использует только голоса, которым не нужна сеть. Если такого голоса нет, оно прямо об этом скажет.

### Шаг 4. Играть

1. Включи авиарежим, если хочешь убедиться, что всё работает без сети.
2. «Добавить книгу» → выбери файл TXT, FB2, EPUB или PDF с текстом. Для пробы подойдёт `sample/vorota_mha.txt`.
3. Открой книгу, выбери героя и режим, нажми «Начать приключение».
4. Пиши действия в поле «Что ты делаешь?».

Быстрые команды без модели: `инвентарь`, `статус`, `журнал`, `задания`, `кто рядом`, `где я`, `сохранить`, `помощь`.

## Что умеет

- **Книги.** TXT (UTF-8, Windows-1251, KOI8-R, DOS-866, UTF-16 — определяется само, можно выбрать вручную), FB2 и FB2 в ZIP,
  EPUB, PDF с текстовым слоем. Сканы PDF, файлы с DRM и повреждённые файлы отклоняются с понятным сообщением.
- **Разбор книги.** Главы, фрагменты по 300–700 знаков, полнотекстовый поиск SQLite FTS5, карточки персонажей, мест, групп,
  предметов и правил мира. Разбор идёт по главам с прогрессом, его можно остановить и продолжить; играть можно после первой главы.
- **Игра.** Свободный ввод, два режима («Ближе к канону» и «Свободная история»), герой книги или свой герой.
- **Правила.** Предметы, монеты, здоровье, место, отношения, задания и журнал хранит движок правил, а не модель.
  Модель только предлагает изменения, движок проверяет каждое.
- **Сохранения.** Автосохранение после каждого хода, три ручных слота, «Переиграть последний ход», резервная копия в ZIP.
- **Озвучка.** Чтение по предложениям по мере генерации, пауза, продолжение, стоп, скорость 0,85–1,15, высота тона, громкость.
- **Скорость.** Замер при первой установке модели, подбор числа потоков, экономичный режим.

## Чего ждать от модели

Qwen3-0.6B очень маленькая. Она пишет по-русски короткие сцены с репликами персонажей, но часто путает падежи и род,
а смысл реплик бывает туманным. Длинную сложную книгу она «не понимает» — игра опирается на поиск по тексту и на
состояние мира, которое ведут правила. Примеры настоящих ответов модели есть в `docs/real-llm-run.md`.

## Сборка из исходников (Windows)

Нужны:

- Android Studio (любая свежая версия) или отдельно JDK 17–21;
- Android SDK: Platform 35, Build-Tools 35.0.0, NDK 27.2.12479018, CMake 3.22.1 (ставятся через SDK Manager в Android Studio).

Шаги:

1. Распакуй архив исходников, например в `C:\zhivaya-kniga` (путь без пробелов и русских букв).
2. Открой папку в Android Studio и дождись синхронизации Gradle — или в командной строке:
   ```
   cd C:\zhivaya-kniga
   echo sdk.dir=C:\\Users\\ИМЯ\\AppData\\Local\\Android\\Sdk > local.properties
   gradlew.bat :app:assembleDebug
   ```
3. Готовый файл: `app\build\outputs\apk\debug\app-debug.apk`.
4. Релизная сборка: `gradlew.bat :app:assembleRelease` → `app\build\outputs\apk\release\app-release.apk`.

Исходники llama.cpp уже лежат в `third_party/llama.cpp`, скачивать их отдельно не нужно.
Первая сборка нативной части занимает несколько минут.

**Про подпись.** Обе сборки подписываются ключом `keystore/zhivaya-kniga.jks` (пароль `livebook` записан в `app/build.gradle.kts`).
Это открытый учебный ключ частной сборки: он нужен, чтобы новые версии ставились поверх старых без потери сохранений.
Для публикации в магазине приложений создай собственный ключ.

**Сборка «всё внутри APK».** Если положить модель в `app/src/main/assets/model.gguf` и собрать проект, получится APK
около 425 МБ, который сам установит модель при первом запуске. Этот вариант в текущей среде не собирался и не проверялся.

## Тесты

```
gradlew.bat :core:test
```

Это 45 тестов логики (импорт, разбор, правила, сохранения, игровой цикл) — они идут без модели.

Тест с настоящей моделью (Linux, нужны cmake и ninja):

```
cmake -S native -B build-host -G Ninja -DCMAKE_BUILD_TYPE=Release && ninja -C build-host livebook_llm
LIVEBOOK_MODEL=/путь/Qwen3-0.6B-Q4_K_M.gguf LIVEBOOK_NATIVE_DIR=$PWD/build-host ./gradlew :core:test --tests '*RealLlmIT'
```

Он проходит 35 ходов по тестовой книге и пишет протокол в `core/build/reports/real-llm.md`.

Тесты на телефоне или эмуляторе (нужен подключённый по USB телефон с включённой отладкой):

```
adb push Qwen3-0.6B-Q4_K_M.gguf /data/local/tmp/model.gguf
gradlew.bat :app:connectedDebugAndroidTest
```

Они проверяют запуск интерфейса, импорт TXT и PDF, поиск по книге, сохранения, состояние голоса, установку модели и генерацию.

## Как устроен ход

1. Быстрые команды («инвентарь», «сохранить») выполняются сразу, без модели.
2. Перемещение, обещание и явная доброта или враждебность к тому, кто рядом, определяются по словам игрока — их решает движок.
3. Из книги достаются 1–3 фрагмента: для текущего места и для действия.
4. Собирается короткий промпт: правила рассказчика, лор сцены, состояние героя, последние события, действие.
5. Модель пишет 1–3 предложения и строку с предложенными изменениями. Формат ответа задан грамматикой (GBNF):
   в ней разрешены только те изменения, которые в этом ходу допускают правила.
6. Движок проверяет каждое изменение ещё раз и применяет только допустимые.
7. Ход записывается в базу одной транзакцией. Если модель дважды дала негодный ответ, игрок видит честное сообщение о сбое,
   мир не меняется.

Скорость держится на двух вещах: неизменная часть промпта остаётся в KV-кеше модели, а ответ ограничен по длине.
