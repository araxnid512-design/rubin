Живая книга

Текстовая игра для Android по вашей собственной книге. Сцены сочиняет нейросеть прямо на телефоне — интернет нужен только чтобы один раз скачать файлы с этой страницы.

Версия 1.1. Приложение проверено в эмуляторе Android 14, но на настоящем телефоне ещё не запускалось — скорость и звучание голоса на вашем устройстве могут отличаться.

  1. Приложение

    Скачать APK zhivaya-kniga-debug.apk · 49 МБ

    Откройте скачанный файл на телефоне и разрешите установку из этого источника. Нужен Android 8 или новее и 64-битный процессор.

    SHA-256: 580819f11e9067ac702ae30998aa013b8e9f45c03568190903efecb41ff4226b

  2. Модель

    Выберите одну. Файл скачивается с Hugging Face.

    Qwen3-1.7B 1,1 ГБ · связный текст, ход дольше
    Qwen3-0.6B 397 МБ · быстро, текст небрежный

    В приложении нажмите «Установить модель из файла» и выберите скачанный файл. Приложение само замерит скорость на вашем телефоне.

  3. Голос рассказчика

    Скачать голос «Дмитрий» golos-dmitri.zip · 67 МБ

    Архив распаковывать не нужно. В приложении: «Настройки» → «Голос рассказчика» → «Установить голос из файла». Без голоса игра работает молча.

    SHA-256: 29ead883949d3187a919ea6ba09f4c286300c75d2dedd99f372d1aab7eee5d91

  4. Книга

    Нажмите «Добавить книгу» и выберите свой файл: TXT, FB2, EPUB или PDF с текстом. Для пробы есть короткая тестовая книга.

    Тестовая книга «Ворота мха» vorota_mha.txt · 4 КБ

После установки

  • Игра работает в авиарежиме: у приложения нет разрешения на доступ к сети.
  • Книги, сохранения и модель хранятся только на телефоне.
  • Скачанные файлы модели и голоса после установки можно удалить из «Загрузок».
